#﻿UrbanNest

UrbanNest is a real-estate platform designed to help people discover properties for buying and renting.

The platform is planned to provide a simple place where users can explore available properties, view property details, compare their options, and connect with property owners or sellers.

In the future, UrbanNest will be extended with JavaScript and backend technologies to support features such as user accounts, property listings, property search and filtering, property submission, and secure communication between property owners and interested buyers or tenants.

The platform will also include a property verification system so that users cannot simply upload random photos or claim someone else's property as their own. Property owners will eventually be required to provide appropriate ownership or authorization documents before a property can be published as a verified listing.
